디맥 판정 분석기 (DmJudge) v0.5.3 — OBS판
=========================================

DJMAX RESPECT V를 플레이하는 동안 화면과 키 입력을 같이 기록해서,
노트 하나하나를 몇 ms 빨리/늦게 쳤는지 실시간으로 보여주는 도구입니다.
게임 메모리를 읽거나 게임 파일을 건드리지 않고, 화면 캡처와 키 입력만 사용합니다.

기준: 노트 "중앙"이 판정선 "정중앙"에 닿는 순간 = 영점 (모든 설정이 0일 때의 판정 순간)
결과와 추천값은 전부 ms 단위입니다. 배속, 해상도, 주사율과 무관하게 자동 계산됩니다.


1. 설치 (처음 한 번)
--------------------
  1) INSTALL.bat 을 더블클릭 → 파이썬(없으면 자동 설치)과 필요한 부품을 이 폴더 안(.venv)에 설치하고,
     바탕화면에 "DmJudge" 바로가기를 만듭니다. (처음엔 5~10분)
  2) 이후로는 바탕화면의 "DmJudge"(또는 이 폴더의 START.bat)로 실행합니다.
     설정과 기록은 이 폴더(config.json, results.json, CSV)에 저장됩니다.
  3) 새 버전: 새로 받은 파일을 이 폴더에 덮어쓰고 INSTALL.bat 을 한 번 더 실행.
  * 오류 내용을 보고 싶으면 run_dev.bat 으로 실행하면 검은 창에 표시됩니다.
    바로가기로 실행하다 오류가 나면 이 폴더에 error_log.txt 가 남습니다.


2. 처음 설정
------------
  1) 디맥을 "보더리스 창" 또는 "창 모드"로 실행하세요. (전체 화면 독점 모드는 캡처가 안 될 수 있음)
  2) 디맥에서 노트가 없고 이펙트도 없는 화면(곡 시작 직전, 일시정지 화면 등)을 띄웁니다.
  3) 분석기의 [영역 보정] 클릭
     - 마우스로 플레이 영역을 드래그: 1번 레인 왼쪽 끝 ~ 마지막 레인 오른쪽 끝, 위쪽 ~ 판정선까지
     - Enter로 확정
     - 다음 창에서 빨간 선이 판정선 정중앙에 오도록 W/S로 조절 (Shift = 크게), A = 자동 찾기
     - 보라색 선 = 추적 한계선. 이 아래는 판정 이펙트, MAX % 글자에 가려지는 구간이라 쓰지 않습니다.
       E/D로 조절하되, 이펙트가 시작되는 높이보다 살짝 위로 두면 됩니다.
     - Enter로 저장
  4) [미리보기]로 노트가 잘 잡히는지 확인 (초록 = 레인 노트, 주황 = 트리거, 하늘 = 사이드 트랙,
     판정선에 빨간 막대 = 노트 도달로 계산된 순간). ESC / Q 또는 창의 X로 닫기.


3. 사용
-------
  - 그냥 플레이하면 됩니다. 4B/5B/6B/8B는 곡마다 자동으로 판별합니다(곡 시작 후 몇 초).
    판별 전에 친 노트도 나중에 포함됩니다. 모드를 고정하려면 상단 "모드"에서 선택하세요.
  - 게임에서 쓰는 "판정 타이밍", "출력 타이밍" 값을 위쪽 칸에 똑같이 입력해 두세요.

  화면 설명
  - 맨 위 상태줄의 "변속 감지 N회 (a~b)" : 지금 곡에서 노트 속도가 바뀐 횟수와 속도 범위(px/ms).
    변속이 없는 곡에선 표시되지 않습니다. 정보용이며 측정 정확도에는 영향이 없습니다.
  - 나만의 판정선 : 실제 판정 기준으로 평균적으로 몇 ms 빨리(-)/늦게(+) 치는지 (중앙값)
  - 흔들림        : 위아래로 얼마나 흔들리는지 (설정으로는 안 줄고 연습으로 줄어드는 값)
  - ±41.67 ms 안  : 지금 설정에서 MAX 100% 범위 안에 들어온 비율
  - 추천          : 실제 기록으로 1ms 단위로 전부 계산해서, ±범위 안에 가장 많이 들어오는 설정값
  - 여유          : 추천값으로 바꿨을 때 가장 빠른/느린 노트가 범위 끝까지 남는 ms
  - 표            : 손 그룹별, 키별 평균 / 흔들림 / 범위 안 비율 / 놓친 노트 / 채터링(키가 짧게 두 번 눌림)

  인디케이터 (OBS판: OBS 브라우저 소스로만 표시, 게임 화면 위에는 아무것도 띄우지 않음)
  - 반투명으로 그려집니다. 선이 없는 곳은 완전히 비쳐서 노트를 가리지 않고,
    선이 많이 겹친 곳일수록 진하고 밝아집니다. 막대 위 옅은 언덕 = 최근 노트들이 몰린 분포.
  - 초록 끝선 사이 = FAST/SLOW 범위(기본 ±41.67), 정중앙 흰 선 = 판정 중심(영점).
  - 인디케이터 모양(전체 길이, 띠 길이)은 항상 같고, "FAST/SLOW 범위 ±"를 바꾸면 막대 양끝 값이
    자동으로 따라 바뀝니다(양끝 = 범위 × 2.4). 예: 범위 ±25 → 양끝 ±60, 범위 ±60 → 양끝 ±144.
    100% 범위와 다르게 정했으면 100% 범위는 회색 짧은 선으로 표시됩니다.
    최근 몇 초("표시 초") 동안 친 노트가 가는 세로선으로 찍히고 시간이 지나면 점점 투명해집니다.
    노란 선 = 방금 친 노트, 빨간 선 = 범위 밖, 아래 회색 삼각형 = 지금 보이는 점들의 평균.
  - 범위 밖으로 친 순간에만 막대 위에 "FAST 42.5ms"(파랑) / "SLOW 47.0ms"(빨강)처럼 영점에서 벗어난 크기가 뜹니다.
    왼손 키에서 난 것은 막대 왼쪽, 오른손 키에서 난 것은 오른쪽에 뜹니다(사이드·트리거도 왼쪽/오른쪽 키 기준, 5B 가운데는 실제로 누른 키 기준).
    떠 있는 시간은 "ms 글자 초"(기본 1.5초)로 바꿀 수 있고, 마지막 30% 동안 흐려집니다.
    점과 글자 모두 누르는 순간 바로 뜹니다. 다만 분석기가 잠깐 화면 흐름을 놓쳐 짐작으로 계산 중이거나
    게임의 FAST/SLOW 글자가 떠 있을 때(노트 위치가 몇 ms 틀어질 수 있음)는 그 판정의 글자만 도달 확인 뒤 띄웁니다.
    바로 띄운 글자가 확정값으로 범위 안이면 즉시 지워집니다.
    (config.json indicator "flash_mode": "auto"(기본) / "instant"(항상 바로) / "confirmed"(항상 확정 뒤))
    안 친 노트에는 아무것도 뜨지 않습니다.
  - "글자 크기 %" = FAST/SLOW 글자와 ms 숫자 크기 (기본 100). 크게 하면 막대 위치는 그대로 두고 글자 자리만 위로 늘어납니다.
    글자는 중앙선을 넘지 않습니다: FAST/SLOW는 중앙선 왼쪽, ms 숫자는 오른쪽 (왼손 글자는 왼쪽, 오른손 글자는 오른쪽).
    자리가 모자라면 그 글자만 자동으로 작아집니다.
  - 방금 친 노트는 굵은 노란 선 + 위쪽 작은 점으로 표시됩니다.
  - "FAST/SLOW 색 반대로" = 글자 색을 FAST 빨강 / SLOW 파랑으로 (기본은 FAST 파랑 / SLOW 빨강).
  - 점은 키를 누른 순간 바로 찍힙니다. 노트가 판정선에 닿기 전이면 내려오는 속도로 계산한
    '예상 도달 시각' 기준으로 찍고, 실제로 닿으면 정확한 값으로 조용히 바로잡습니다(차이는 보통 1~2ms).
    EARLY/LATE 글자도 누르는 순간 판단합니다. "FAST/SLOW 범위 ±"를 따로 정하면 글자는 그 범위를 따릅니다.
  - 인디케이터의 0이 정확하려면 기준점이 맞아야 합니다. 100% 밖 노트가 몇 개 나온 곡에서
    결과 화면이 나오는 곡을 3곡 이상 끝까지 치면 영점 보정 추천이 자동으로 계산됩니다(아래 "영점 보정").

  OBS 인디케이터 (브라우저 소스)
  - 인디케이터·OBS 설정, 투명, 새 캡처 방식, 키 기록 범위는 [▸ 인디케이터 · OBS · 기타 설정]을 눌러 펼쳐야 보입니다
    (그래프 자리를 넓히려고 평소엔 접어 둠. 펼침 상태는 저장됨).
  - [OBS 인디케이터] 체크 → [주소 복사] → OBS 소스 추가 → 브라우저 → URL에 붙여넣기 (기본 http://127.0.0.1:8777/).
    너비·높이는 분석기 아래 "브라우저 소스 크기"대로. 배경 투명. OBS판은 기본으로 켜져 있습니다.
    (표시 초, ms 글자 초, 글자 크기, FAST/SLOW 표시, 색 반대로 등 인디케이터 설정이 그대로 적용됨)
  - "크기 %" (50~400, 기본 100) = 100%면 원래 게임 위 인디케이터와 똑같은 크기·모양(영역 보정한 기어 폭 × 45%, 높이 58 + 글자 크기).
    다른 %는 그 크기로 직접 그려서 선명합니다. OBS에서 소스를 늘리거나 줄이지 마세요(줄이면 얇고 옅은 선이 지워짐).
  - 127.0.0.1(내 PC 안)에만 열려서 다른 PC·인터넷에서는 접속할 수 없습니다. 8777을 다른 프로그램이 쓰고 있으면
    8778, 8779… 순서로 열고 바뀐 주소를 화면에 보여줍니다. (config.json "obs": {"port": 8777, "scale": 1.0})
  - OBS나 브라우저가 연결되어 있지 않으면 그림을 만들지 않습니다(부하 없음).

  키 입력 기록 범위
  - "게임 창이 맨 앞일 때만 키 기록"(기본 켜짐): 맨 앞 창 제목에 DJMAX가 들어 있거나 분석기 창일 때만 키를 받습니다.
    다른 창에서 친 키는 키 입력 프로세스 안에서 바로 버려집니다. 게임 프로세스는 열지 않고 창 제목만 봅니다.
    상태줄의 키 항목이 "게임 창 밖 (키 무시 중)"으로 바뀌면 그 상태입니다. 디맥을 켜고 쳤는데도 계속 그렇게 뜨면
    이 체크를 끄고 Issues에 알려 주세요. (config.json "focus_only")
  - 어느 경우든 설정한 게임 키가 아니면 기록하지 않습니다.

  곡 끝 감지 · 결과 화면 자동 읽기
  - 기어의 판정선이 화면에서 사라지면 곡이 끝난 것으로 봅니다. 판정선 모양은 곡이 시작될 때 분석기가 스스로 기억하므로
    기어 스킨과 상관없습니다. 판정 이펙트나 롱노트가 잠깐 가리는 것은 곡 끝으로 보지 않습니다.
    곡이 끝난 뒤 화면 전환 그림 등이 노트로 잘못 잡히지 않게, 판정선이 다시 보일 때까지는 노트를 세지 않습니다.
  - 곡이 끝나고 결과 화면(JUDGEMENT DETAILS)이 뜨면 분석기가 화면을 한 장 찍어 MAX 100%~BREAK 숫자를 읽습니다.
    상단 상태줄에 "결과 화면 읽음: MAX 100% … · 100% 아님 … · BREAK … (분석기 범위 밖 …)"가 뜹니다.
  - 읽은 결과는 그 곡의 기록과 짝지어 이 폴더의 results.json에 저장됩니다(껐다 켜도 남음, 최근 60곡).
  - 보더리스/전체 화면 기준입니다(해상도는 자동 맞춤). 숫자를 확실히 읽지 못하면 아무것도 저장하지 않습니다.

  영점 보정 (결과 화면)
  - [영점 보정 (결과 화면)] 창에 모은 곡 목록과 곡마다 "게임 100% 아님 / 분석기 범위 밖" 개수가 나옵니다.
  - 3곡 이상 모이면, 모든 곡의 개수가 가장 잘 맞는 영점 보정값과 그 범위(95%)를 계산합니다.
    MAX 100% 범위 ±41.67 ms(2.5/60초)와 분석기의 측정 흔들림(약 1.5 ms)을 반영한 계산입니다.
    경계 근처 노트가 많은 어려운 곡(조금 못 친 판)일수록 정확해집니다.
  - [추천값 적용]으로 바로 적용. 목록에서 더블클릭하면 그 곡을 계산에서 빼거나 다시 넣습니다.
  - 지금 보정값이 맞는 범위 밖이면 메인 창에 노란 알림이 뜹니다([보정 적용] / [무시]).
  - 결과 화면을 못 읽었을 때는 창 아래에 그 곡의 "100% 아닌 개수(90%~1% 합, BREAK 제외)"를 직접 넣을 수 있습니다.

  게임 모드 · 그룹별 영점 (루머 확인용)
  - 모드 버튼 옆 "게임 모드"에서 프리스타일 / 래더 / 버서스 매치 / 미션을 고릅니다. 결과 화면을 읽을 때
    버튼 모드·게임 모드·노트별 레인이 같이 저장됩니다.
  - [영점 보정 (결과 화면)] 창 아래에 그룹(버튼 모드 × 게임 모드)별 추천 영점과 맞는 범위가 나옵니다.
    3곡 이상 모인 그룹끼리 범위가 안 겹치면 "차이 있음"으로 알려줍니다.
  - "그룹별 영점 따로 쓰기"를 켜면: [추천값 적용]이 지금 그룹의 값으로 저장되고, 버튼 모드·게임 모드가
    바뀌면 그 그룹에 저장된 영점으로 자동 전환됩니다. (차이가 확인되기 전까지는 꺼 두는 걸 권장)
  - 키(레인)별 차이는 결과 화면 숫자만으로는 알 수 없어서, 게임의 FAST/SLOW 표시를 켜고 친 기록(_raw.csv)으로
    따로 분석합니다.

  판정 종류 (100% 범위 옆 · FAST/SLOW 범위 옆, 따로따로)
  - 노멀 판정 ±41.67 / 하드 판정 ±20.83 / 맥스 판정 ±10.42 / 사용자 설정
  - 100% 범위 쪽 = 게임에서 고른 판정(추천 판정 타이밍, "±… 안" 비율, 키를 노트에 짝짓는 거리, 결과 기록의 판정 종류).
  - FAST/SLOW 범위 쪽 = 인디케이터·그래프의 FAST/SLOW 기준 (연습용으로 따로 좁혀도 됨).
  - 고르면 그 칸 숫자가 바뀌고, 숫자를 직접 바꾸면 "사용자 설정". 두 칸은 서로 자동으로 바뀌지 않습니다.
  - 하드 판정은 측정으로 확인: 100% 범위 ±20.91 (95% 20.21~21.61, 8곡 약 1만 노트) → 노멀의 절반(20.83),
    단계 폭은 아직 불확실: 영상 등급 글자로 9.0 (95% 8.1~9.9) → 16.67이 아닌 건 확실, 8.33인지는 추가 측정 중.
    영점은 노멀과 같음(+6.92).
  - 맥스 판정도 측정으로 확인: 100% 범위 ±10.02 (FAST/SLOW 글자, 대략 9.1~10.9) / ±10.20 (영상 등급 글자),
    한 단계 4.35ms (95% 4.05~4.60, 영상 116노트) → 노멀의 1/4(±10.42, 4.17)과 맞음. 영점 +7.1 (노멀과 같음). 1곡이라 추가 측정 중.
  - 키 입력과 노트를 짝짓는 최대 거리도 판정 종류를 따라감: 100% 범위 x 4.6 (= MAX 10% 끝).
    노멀은 예전 그대로(늦은 쪽 150 · 이른 쪽 190), 하드는 ±95.8까지만 → 게임이 무시하는 헛친 키에
    'FAST 160ms' 같은 큰 글자가 뜨지 않음.
  - config.json에 "fs_presets": {"hard": 20.83, "max": 10.42} 처럼 넣으면 바꿀 수 있습니다.
  - 결과 화면을 읽을 때 그때 고른 판정 종류가 같이 저장됩니다(results.json, 최근 120곡).
    영점 보정 추천은 노멀 판정 곡만으로 계산하고, 하드·맥스 곡은 실제 판정 범위를 찾는 데 씁니다.
    → 하드/맥스로 칠 때는 판정 종류를 먼저 하드/맥스로 바꿔 두고 치세요.

  인디케이터 표시 ("인디케이터 표시" 아래 줄)
  - 인디케이터 막대 표시 : 켜기/끄기. 꺼도 FAST/SLOW 글자·ms는 그대로 보임.
  - FAST/SLOW 표시      : 표기 안 함 / FAST/SLOW 범위를 벗어났을 때 / 100% 범위를 벗어났을 때
  - ms 표시             : 표기 안 함
                          / 모든 노트 (가운데에 노트마다 표시, 다음 노트가 오면 바뀜. 범위 안 = 흰색,
                            FAST/SLOW 범위 밖 = 파랑·빨강. FAST/SLOW 글자는 숫자 왼쪽에 남아 있다가
                            "ms 글자 초"가 지나면 서서히 사라짐, 그 전에 새 FAST/SLOW가 나오면 바뀜)
                          / FAST/SLOW 범위를 벗어났을 때만 / 100% 범위를 벗어났을 때만
                          ("모든 노트"가 아니면 친 손 쪽(왼손 왼쪽, 오른손 오른쪽)에 "FAST -52.3ms"처럼 잠깐 뜸)
  - 선 연해짐           : 약하게(예전 그대로) / 보통 / 강하게(처음 0.5초는 진하게, 이후 빠르게 옅어져 최근 것만 도드라짐)
  - 글자 연해짐         : FAST/SLOW·ms 글자가 사라지는 방식. 끝에서만(마지막 30%, 예전 그대로) / 보통(40%부터 서서히)
                          / 뜨자마자 서서히. 전체 표시 시간은 "ms 글자 초".
  - 예) 연습용: FAST/SLOW 범위를 좁히고, FAST/SLOW 표시 = 100% 범위 밖, ms 표시 = 모든 노트
        → 패슬 범위 밖은 숫자 색만 바뀌고, FAST/SLOW 글자는 실제 100% 밖일 때만.
  - 글자가 떠 있는 시간 = "ms 글자 초".

  그래프 (메뉴에서 골라 보기)
  - 오차 분포       : 지금까지 기록의 빠름/느림 분포 (예전 히스토그램)
  - 곡 흐름         : 세로축 = 인디케이터 범위(FAST/SLOW 범위 x2.4, 기본 ±100ms) 고정.
                      위 파랑 색칠 = 범위 안에서 빠르게 친 노트끼리 평균, 아래 빨강 색칠 = 범위 안에서 느리게 친 노트끼리 평균.
                      노란 선 = 색칠을 따라가다가 범위 밖으로 튄 노트가 있는 곳에서 그 노트 높이까지 언덕처럼 솟음(위아래 같음).
                      점 = 튄 노트의 실제 위치, 세로축(±100)을 넘으면 위·아래 끝에 삼각형.
                      가운데 어두운 띠 = FAST/SLOW 안쪽(±41.67).
  - 밀도 (초당 노트): 1초마다 지나간 노트 수. 흰 점선 = 평균, 빨간 막대 = 가장 빽빽한 구간.
  - 판정 단계       : FAST/SLOW 범위(설정값)를 가운데 100%로 두고, 바깥으로 범위의 0.4배마다 한 단계씩
                      (기본 41.67이면 16.67ms = 게임의 MAX 90%·80%·70% … 와 같은 간격, 범위를 줄이면 같은 비율로 줄어듦) 몇 개씩 쳤는지 가로 막대로. 위 = FAST, 아래 = SLOW.
                      막대 길이는 제곱근 눈금(100%가 너무 길어 나머지가 안 보이는 것 방지), 옆에 개수와 비율.
  - 2개 같이 보기   : 통계표를 숨기고 그래프 2개를 위아래로.
                      · 곡 흐름 + 밀도  : 두 그래프의 가로축(곡 시작~끝)이 똑같이 맞춰져 있어 같은 시점끼리 위아래로 비교 가능
                      · 오차 분포 + 판정 단계

  화면 배치
  - 설정 줄과 아래 버튼 줄은 창 폭에 맞춰 자동으로 줄바꿈됩니다 (창을 좁혀도 옆으로 잘리지 않음).
  - 맨 위 상태 줄과 그래프 설명 줄은 높이가 고정이라 글자가 길어져도 화면이 위아래로 들썩이지 않습니다.
  - 아래 버튼 줄(초기화·일시정지 …)은 창 맨 아래에 고정. 창이 짧으면 통계표가 먼저 줄어듭니다.
  - 숫자 칸에는 숫자만 입력됩니다(소수 칸은 소수점, 음수 가능한 칸은 - 까지).
  - 저장된 창 크기가 화면보다 크면 켤 때 화면 안에 들어오게 줄입니다.
  - 곡을 치는 중에는 지금 곡, 곡이 끝나면 그 곡 전체를 보여줍니다.

  기록 불러오기
  - [기록 불러오기]로 예전에 [CSV 저장]한 파일(dmjudge_….csv 또는 …_raw.csv)을 고르면, 그 기록을 다시 흘려 넣어
    곡별로 그래프 3개와 FAST/SLOW 개수, 결과 화면 숫자(읽었던 곡)를 보여줍니다. 진단용 _raw.csv가 같이 있어야 합니다.

  측정 방법
  - 눈판정 측정 : 게임 소리를 끄고 정박 폭타/동치 곡 → "추천 판정 타이밍"을 적용
  - 귀판정 측정 : 판정 타이밍은 그대로 두고, 눈판정 없이 소리에만 맞춰 쉬운 정박 곡 → "추천 출력 타이밍"을 적용
  - 귀판정 싱크 = 판정 타이밍 − 출력 타이밍
  - 판정선을 옮기면 손이 다시 적응하므로, 바꾼 뒤 [초기화]하고 다시 재보는 걸 권장합니다.

  키 설정
  - [키 설정]에서 모드별로 레인마다 키를 지정합니다. "추가"를 누른 뒤 키를 누르면 됩니다.
  - 한 레인에 여러 키 가능 (예: 5B 가운데 레인 = F 또는 Num4)
  - 오른쪽 칸은 손 그룹 이름입니다. 통계가 이 이름으로 묶입니다.
  - 넘패드 키와 방향키(Num6 / →)는 NumLock 상태와 상관없이 구분됩니다.

  기본 키
  - 4B : D F Num4 Num5 / 사이드 Space, Num+
  - 5B : S D (F 또는 Num4) Num5 Num6 / 사이드 Space, Num0
  - 6B : S D F Num4 Num5 Num6 / 사이드 Space, Num0
  - 8B : S D F Num4 Num5 Num6 / 트리거 Space, → / 사이드 CapsLock, Num+


4. 알아둘 점
------------
  - 변속(BPM 변화) 곡: 화면 전체 노트의 움직임으로 스크롤을 계속 따라가므로 대응됩니다.
    변속 순간에 화면에 보이는 노트가 하나도 없어서 확인이 불가능한 노트는 자동으로 통계에서 빠집니다.
  - 창 아래쪽 "입력→표시 x ms" = 키를 누른 뒤 인디케이터를 그리기까지 걸린 시간(모니터 표시 지연 제외).
  - 상단에 "처리 지연" 경고가 뜨면 캡처 시각이 부정확해질 수 있습니다. 다른 프로그램을 줄여 주세요.
  - 롱노트는 시작 부분만 측정합니다.
  - 화면 캡처·표시 과정의 지연 때문에 분석기의 영점이 게임의 실제 판정 중심과 조금 어긋날 수 있습니다.
  - 영점 보정 추천은 결과 화면 개수로만 계산합니다(예전의 FAST/SLOW 글자 기반 알림은 밀도 높은 곡에서
    한쪽으로 치우쳐 없앴습니다). "새 캡처 방식"을 켰을 때와 껐을 때 보정값은 따로 기억됩니다.
  - "영점 보정" 칸: 보정값을 직접 바꿀 수 있습니다(0.5 ms 단위). 게임은 100%인데 FAST가 뜨면 + 쪽으로,
    SLOW가 뜨면 - 쪽으로 옮기세요. 바꾸는 즉시 지금까지 기록과 인디케이터에 반영됩니다.
  - 손/키별 차이, 흔들림, 설정 전후 비교는 영점 보정과 상관없이 정확합니다.
  - "100% 범위 ±"는 MAX 100% 판정 범위(기본 41.67 = 2.5/60초)입니다. 보정과 추천값 계산에 쓰이니 그대로 두세요.
  - "FAST/SLOW 범위 ±"는 FAST/SLOW로 셀 기준입니다(기본 41.67 = 게임과 같음). 더 엄격하게 연습하고
    싶으면 줄이세요. 개수와 인디케이터의 EARLY/LATE 글자가 이 값을 따릅니다.
  - 노트 스킨: 색(파랑·하늘·주황·빨강·노랑·흰색 등)과 모양(막대, 동그라미, 마름모, 별·하트 같은 아이콘,
    속이 빈 테두리, 레인보다 좁은 작은 노트)에 상관없이 인식합니다. 썸네일의 배경은 상관없습니다.
    어둡거나 반투명한 노트 스킨이면 "어두운 노트 스킨"을 켜세요. 레인 폭의 1/3보다 훨씬 좁은 노트는
    잡히지 않을 수 있습니다. 스킨을 바꾼 뒤에는 [미리보기]로 초록 테두리가 노트를 따라가는지 확인하세요.
  - 노트 모양마다 "노트 중앙"으로 보는 위치가 1~2ms 다를 수 있습니다. 스킨을 바꾼 뒤 보정 추천 알림이
    뜨면 [보정 적용]을 누르면 됩니다.
  - 패널(기어) 스킨을 바꾸면 플레이 영역 위치가 달라질 수 있으니 [영역 보정]을 다시 하세요.


진단 / 비교
-----------
  - [CSV 저장]을 누르면 기록 CSV와 함께 "_raw.csv"(키 입력·노트 도달 원본, 설정 요약)가 같이 저장됩니다.
    문제가 생기면 [초기화] → 한 곡 → 결과 화면에서 [CSV 저장] 후 _raw.csv 파일을 보내주세요.
  - "동그란 노트 스킨": 고리(테두리) 모양 동그란 노트를 쓸 때 켜세요. 노트 하나가 위·아래 테두리 두 개로
    쪼개져 잡히는 것을 한 노트로 합칩니다. 막대 모양 노트에서는 끄세요(켜면 화면의 고정 글자를 합칠 수 있음).
    쪼개짐이 많이 보이면 상단에 알림이 뜹니다.
  - "판정 이펙트가 큰 스킨": 판정선 위로 높이 솟는 판정 이펙트(캔 모양 등)를 쓸 때 켜세요. 추적 한계선을
    플레이 영역 높이의 30% 지점까지 올려서 이펙트가 노트로 섞이지 않게 합니다. 기본 스킨에서는 끄세요
    (판정선 근처를 덜 보게 되어 정확도가 조금 떨어짐).
  - 곡 시작/전환 화면의 번쩍임처럼 같은 레인에 몇 ms 간격으로 붙어 나오는 가짜 노트는 자동으로 거릅니다.
  - 화면 저장(진단): 누르는 순간의 예상값과 확정값이 10ms 넘게 다르면, 그 순간 앞뒤 1.2초 동안 분석기가 본 화면을
    프로그램 폴더의 dumps 폴더에 저장합니다(한 번 실행에 최대 15개, 개당 수 MB). 문제가 생긴 판의 _raw.csv와 함께 보내주세요.
    필요 없으면 config.json에 "frame_dump": false.
  - "새 캡처 방식" 체크 = 캡처 전용 스레드가 프레임 시각을 기록(v0.3.7~). 끄면 예전 방식. 바꾸면 캡처가 다시 시작됩니다.
